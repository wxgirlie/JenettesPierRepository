About this dataset

This dashboard displays NOAA/NCEI Storm Events records with a reported location within 50 statute miles of Jennette's Pier.

When an event has multiple qualifying reported locations, the closest reported location is used for the main event record. Distance is calculated using great-circle (Haversine) distance.
